# 豆酱工作室官网

纯静态 HTML/CSS，无构建依赖、无第三方字体、无脚本和统计工具。

- 官网：https://mrduzz.github.io/doujiang-studio/
- 发布仓库：https://github.com/MrDuZz/doujiang-studio
- GitHub Pages：`main` 分支根目录，HTTPS。
- 本地预览：在本目录运行 `python3 -m http.server 8793 --bind 127.0.0.1`。

只发布本目录中的 `index.html`、`style.css`、`.nojekyll`、`assets/` 和本说明。游戏源码仓库不随网站发布。

素材来源：`assets/logo.png` 为用户于 2026-10-28 提供的 Logo，原图直接复制；`assets/internet-cafe-era.png` 来自项目 2026-10-22 TapTap 实机素材 `final/01-hall-orders.png`，未经改画。联系入口为本公开仓库的 Issues 留言区。

网站是工作室介绍页，可用作官网链接。没有发布游戏隐私政策，也没有修改 TapTap 后台字段。
